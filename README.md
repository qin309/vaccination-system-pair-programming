## 二、本地部署步骤

### 环境要求

| 环境 | 版本 |
|------|------|
| Java JDK | 11 |
| Maven | 3.6 |
| Node.js | 16 |
| MySQL | 8.0 |

### （1）数据库初始化

```sql
CREATE DATABASE vaccination_system;
USE vaccination_system;
-- 执行 doc/sql/schema.sql 建表
-- 执行 doc/sql/data.sql 初始化测试数据
```

### （2）后端启动

```bash
cd vaccination-system-backend

# 直接使用Maven运行（H2数据库自动初始化）
mvn spring-boot:run
```

后端启动成功后访问：http://localhost:8080

### （3）前端启动

```bash
cd vaccination-system-frontend/user-app

# 安装依赖
npm install

# 启动开发服务器
npm run dev

# 访问 http://localhost:5173
```
